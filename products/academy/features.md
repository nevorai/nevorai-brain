# Nevorai Academy: features
Last checked: 2026-11-07.

## Features
Starter: students, attendance, fees, parent app (100 students). Professional: match centre, coach module, automation, campaigns, online fee payment (500 students). Enterprise: AI reports, custom branding, API, unlimited students.
