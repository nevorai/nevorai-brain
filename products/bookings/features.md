# Nevorai Bookings: features
Last checked: 2026-11-07.

## Features
Meeting types, availability, confirmations, reminders, a Connect page showing the next meetings. Pro: no Nevorai name on the page and emails, up to 200 meeting types, priority help.
## Integrations

### Works with
Nevorai Connect (Bookings page in the menu), WhatsApp links.
