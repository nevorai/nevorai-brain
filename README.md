# Nevorai brain

The one place that holds everything our AI employees (and our team) know about Nevorai: company, products, prices, offers, ads, how to reply, objections, support. Nevorai Connect reads this repo as a Knowledge source, so every file here becomes an answer a customer can get on WhatsApp.

## How it is used
- Connect reads the repo once a day (and when a source is refreshed), cuts every file into pieces of about 900 characters under their nearest heading, and stores them. At reply time the AI fetches the 5 best pieces in ONE database call. So the repo never slows a reply; it only makes it correct.
- Because of that: **one fact per heading, short sections, plain words.** A heading is what the AI finds; a 2,000-word page with one heading is found badly.
- Prices live ONLY in `products/<product>/pricing.md`, generated by `tools/build-pricing.py` from the live price tables. Never type a price anywhere else; link to the pricing file instead.
- Everything here is customer-safe: the repo is public (Connect reads only public repos). Nothing private, no keys, no customer names, no real costs or margins.
- Every file starts with `Last checked: <date>`. `tools/check.py` fails the repo when a file has no date, a price appears outside pricing.md, or a source passes 60 files. Connect reads at most 60 files per source, so the repo is connected as two Knowledge sources: `https://github.com/nevorai/nevorai-brain/tree/main/products` and `https://github.com/nevorai/nevorai-brain` (keep the non-product files under 60).

## Folders
| Folder | What it holds |
|---|---|
| company/ | who we are, contact and hours, policies (payments, refunds, data), how the AI should write |
| products/<name>/ | overview (what, who for, how it works, how to start, uses), features (with integrations), pricing (generated), faq, how-to, limits-and-issues |
| offers/ | the AI tech department for businesses, the AI employees |
| personas/ | who the customers are and what each one really asks |
| ads/ | one file per ad or link: what the person saw, the first reply, what to ask next |
| playbooks/ | one file per AI employee: tone, do and don't, when to hand over |
| objections/ | "too costly", "will think", "already use X", with the reply |
| compare/ | us against the tools people already use, facts only |
| glossary/ | Hinglish words and phrases customers use, and what they mean |
| trust/ | security, data, testimonials (only with written consent) |
| support/ | troubleshooting steps, how to escalate |
| tests/ | real questions with the right answers; used to test every AI employee before it goes live |

## How to add or change something
1. Edit the file (or add one, in the right folder, with `Last checked`).
2. Run `python3 tools/check.py`.
3. Commit and push. Connect picks it up within a day; press Refresh in Settings → AI replies → Knowledge to do it now.
